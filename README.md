# Chaitanya Kumar Upadhyay — Professional Portfolio

An independent, public-safe professional portfolio for a Senior Technical Program Manager specialising in cloud governance, security delivery and enterprise AI platforms.

## Before publishing

- Review every statement for accuracy and public-release approval.
- Do not add employer names, client names, screenshots, architecture diagrams, private URLs, or unapproved metrics.
- Keep `disclaimer.html` linked from the public footer.
- Update the LinkedIn URL if it changes.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.

## Publishing

This site is designed for GitHub Pages. Create a public repository, upload these files, then enable Pages from the repository's `main` branch in GitHub settings.
